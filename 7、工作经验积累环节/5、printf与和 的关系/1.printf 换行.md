1、Linux编译环境下和win编译环境下的 \r\n 含义不同，在这两种环境下，\r\n 的含义相反

    在Linux 下  : 
        \r : 是将光标移动到本行开头
        \n : 是换行

```C
int main（）{
 
    printf("123");
    printf("\r");
    printf("abc");
    printf("***");
    printf("\n");
    return 0;
 
}
```

可以尝试一下这个case “\r ”是指将光标移到本行开头，使用 printf 输出会从光标开始覆盖内容，printf 是向 stdout 文件输出内容，所以会将打印的内容覆盖掉；
